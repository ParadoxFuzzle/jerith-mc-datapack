# Jerith Scripts

Minecraft datapack and MyCommand scripts for the Jerith server: gameplay
functions, custom items, spell effects, minigames, and the chat commands that
drive them. Everything here runs on vanilla assets; no resource pack is
required.

As you edit, add, or remove from the functions and commands please comment your code with what each function is suppoused to do so whoever comes in behind you doesn't have to spend 20 minutes scratching their balls.
